# One Line, One Chill

One line of horror, under 200 characters: a single sentence that frightens in one breath.

Entry: `The smart speaker in the empty house whispered my name at 3 a.m., in my own voice, and asked why I had stopped answering.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
